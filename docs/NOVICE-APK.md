# 新手 Alpha 安装与恢复

版本：`1.95-peng7.2-alpha.1`，versionCode `137`。这是首个带安装后引导的测试版，尚未完成跨品牌真机适配。

## 下载哪个文件

从 [本版本 Releases](https://github.com/alex19950221/peng7-tv-kit/releases/tag/v1.95-peng7.2-alpha.1) 下载本项目自己构建、签名的 APK。

| 文件 | 用途 |
| --- | --- |
| `peng7-tv-kit-1.95-peng7.2-alpha.1-guard.apk` | 优先体验包：不声明系统 HOME，安装后从应用列表打开 Aerial，再跟随守护引导。可避开部分固件对桌面类 APK 的安装限制，但不能保证所有固件都接受安装 |
| `peng7-tv-kit-1.95-peng7.2-alpha.1-standard.apk` | 标准桌面包：声明系统 HOME，适合允许第三方桌面且需要系统桌面选择器的设备 |
| `SHA256SUMS.txt` | 两个 APK 的文件校验值 |

两个包是同一应用的不同变体，**选择一个即可**。安装后名称为 **Aerial**；包名 `app.orchard.tv` 与上游相同。本项目签名与 Aerial 官方签名不同，不能直接覆盖官方包。已有官方版时先处理自己的布局、照片与其他数据，不要为了安装直接清空应用。

发布证书 SHA256：`0649d40cc7bb4c9bb6f3bf3089397aa4ddb1e8d3b08637f8a68676b8c5090f82`。这是证书公开指纹，私钥不会分发。

## 小白操作流程

1. **安装并打开。** 按电视允许的 U 盘、本地安装或厂商推送方式安装，出现提示时在电视确认。具体限制按机型和固件判断。
2. **检查设备。** 首次打开显示型号、Android 版本和应用架构；上下键移动，确认键选择。显示设备信息只证明可以读取信息，不表示完整适配。
3. **授权桌面守护。** 新手流程默认推荐开启守护，点击“前往系统授权”，在无障碍页面启用 Aerial 后返回。系统授权仍由使用者亲自确认。
4. **进入桌面。** 引导检测到系统授权后显示“完成设置，进入桌面”。首次设置尚未完成前，后台不会自行补开守护。
5. **按需配置其他应用。** 桌面只提供已安装应用的入口，不打包第三方应用、代理订阅或会员。已有影音与代理功能沿用项目原来的配置方式。

支持的系统会直接打开授权页；某些国产固件没有此入口。此时引导会明确提示“需要电脑辅助”，并提供“暂不启用，先体验桌面”。**并非所有电视都能只靠一个 APK 完成守护授权与开机配置。** 对应机型仍参考 [安装说明](SETUP.md) 和固定上游的设备文档。

授权后请实际检查 HOME 键、重启、待机唤醒、HDMI 和原有会员应用，再判断自己的固件是否可长期使用。

## 关闭守护与回到原桌面

在 Aerial 控制中心打开 **“新手设置与恢复 → 关闭守护与恢复”**：

- **关闭桌面守护**：记录关闭选择并停用本应用自己的守护组件。后台恢复和开机逻辑会遵守这个选择，不重写其他无障碍服务。
- **打开原桌面**：能识别安装前的默认桌面时，提供直达入口；此操作也会关闭本应用的守护。
- **选择默认桌面 / 打开电视设置**：如果曾手动修改系统默认桌面或厂商开机应用，需在对应设置中选回原值。本 APK 不声称能统一修改所有品牌的开机设置。

已设置的家长密码和儿童模式仍保护设置入口，不通过新手引导绕过。

需要重新启用时，从相同入口返回守护步骤，再前往系统授权。关闭与重新开启都不需要卸载其他应用。

## 这一版实际验证了什么

| 验证 | 范围与结果 |
| --- | --- |
| 定向自动化测试 | 36 项通过；包含 Android API 23 / 26 / 28 的守护选择逻辑，以及遥控器、授权状态、跳过设置、家长密码和原有影音功能测试 |
| 构建 | Standard / Guard Release 均通过；NewApi 作为致命 lint 检查，构建最低系统要求仍为 Android 5.0 / API 21 |
| 签名与资源 | 使用项目自己的 RSA 3072 位证书；APK 包含上游 MIT 与字体 OFL 许可文本 |
| Android 7.0 / API 24 模拟器 | 1080p 电视屏幕配置；验证首次引导、打开系统授权页、确认授权、返回识别、进入桌面、再次打开设置、关闭守护、返回原桌面、重启后保持关闭 |
| 真实电视 | 新手 Alpha 尚未实测。README 中雷鸟 `1.95-peng7.1-guard` 的历史真机结果不代表本 Alpha 已通过真机验证 |

模拟器使用通用 Android 系统镜像与电视屏幕配置，不等同于通过 Android TV / Google TV 或各厂商固件认证。也没有以模拟器的 x86 环境替代 ARM 真机验证。

两个 APK 包含 `armeabi-v7a`、`arm64-v8a`、`x86`、`x86_64` 的原生依赖。包含架构并不保证对应硬件上的所有功能都可用。三星 Tizen、LG webOS 等非 Android 系统不能按本 APK 的方式安装使用。

本版仍待验证：Android 新版本的安装与权限流程、各品牌的开机与待机恢复、低内存机型表现，以及不同客户端的播放兼容性。请将机型、固件、Android 版本、ABI、具体问题与脱敏后的错误信息提交到 Issues。

## 从源码复现

源码基于锁定的 Aerial 提交与本仓库完整补丁。按 [构建文档](BUILD.md) 生成自己的签名包；自己的签名不会与本发布证书相同。

默认启用是产品的推荐流程，**不是绕过系统授权**。Android 无障碍服务由用户在设置中显式启用，参见 [Android 官方 API 文档](https://developer.android.com/reference/android/accessibilityservice/AccessibilityService)。
